# Previous skill collection

Archived on 2026-10-27 when the active collection switched to tstack plus the existing `upload-file` skill.

`skills/` preserves the former active, disabled, and archived skill directories, including their supporting files, credits, and licenses. `profiles/`, `upstreams.json`, the previous collection README, P3 setup helper, and affected tests preserve the old configuration.

This directory is excluded from installation. To restore a skill, copy it into `skills/active/` at the repository root, add an update source in `upstreams.json`, and select it in a profile. Do not install this archive recursively.
